# studio414

Animated agency website: graphic design, branding, digital marketing, SEO, social media and web development.

Built with Next.js, Tailwind CSS, Motion and Lenis.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Edit content

The brand name, logo, contact details, services, work, stats, testimonials and FAQs are all in `src/lib/site.ts`.
To use a logo, put it at `public/logo.svg` and set `logo: "/logo.svg"` in that file.
